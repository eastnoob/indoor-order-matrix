# D6 enclosed interior and residual tolerance replay

The private B2 enclosure now proposes each measured enclosed interior as a separate AnalysisDomain candidate. Each candidate subtracts measured structural sections, so detached columns remain holes. The previous single 307.5600 m² exterior envelope is historical evidence, not a selectable interior. This change does not alter factual source meshes or activate a candidate automatically.

`aperture_residual_tolerance_m2` is an optional B2 request value. Its effective default is `1e-5` m² (10 mm²); `0` retains every positive-area residual as potentially significant. The request validator rejects booleans, negative values, and nonfinite values. This threshold only decides whether an unresolved host projection-minus-cut residual blocks a local candidate. The separate `aperture_area_budget_m2` still governs leaf and authored-opening span qualification. Every residual retains its measured geometry and `significant_residual` flag in diagnostics. The handoff request identity includes the supplied policy, so changing the tolerance invalidates an active session choice.

The frozen IFC replay in [run_001](../../../outputs/design/d6_inner_space_tolerance/run_001/measurements.json) produced five interiors with areas 4.5105, 4.8021, 206.5209, 56.0400, and 6.1724 m². A follow-up nested-wall correction was checked in [run_002](../../../outputs/design/d6_inner_space_tolerance/run_002/measurements.json), leaving run_001 intact. The five measured areas are unchanged within floating-point precision. Two structural holes remain; total positive-area structural overlap is 0. All five derived meshes projected exactly back to their candidate polygons. [The current comparison plot](../../../outputs/design/d6_inner_space_tolerance/run_002/before_after.png) shows wall and column occupancy against the old envelope and new interiors.

A focused nested-shell fixture exposed a duplicate child room: subtraction of wall mass split the parent interior but left the child wall's empty center inside it. The parent now subtracts each contained detached wall shell's filled exterior, while the child shell emits its own room. The corrected fixture yields two positive-area-disjoint interiors (116.09 and 12.25 m²), with the parent's inner-shell and column holes intact. Wall references and unresolved residual attribution use the final local scopes; a significant outer-wall residual affects only the surrounding room. Source records remain unchanged. The affected geometry, enclosure, and canonical-layout suites passed: 88 tests.

A11 and A12 measure 3.497 and 1.422 mm². Both remain diagnostic records and fall below the default. With threshold `0`, both are significant; A11 blocks local candidate S3, while A12 does not touch an enclosed candidate boundary. Neither is reclassified as an authored opening or used to add physical wall mass.

The original exact projection check exposed a 1.1e-15 m² discrepancy in the large holed interior. Triangulation and mesh transport preserved the polygon; the shared projection serializer removed a nearly collinear boundary vertex using a 1e-9 cross-product tolerance. It now removes only exactly collinear vertices, preserving the measured topology and allowing the exact check to pass.

There is currently no implemented AnalysisDomain selector UI in this repository; `scripts/design/analysis_domain_ui` is a static design probe. A future control should edit `aperture_residual_tolerance_m2` in **m²**, display the 10 mm² default, allow `0`, reject invalid values before submitting, and refresh the handoff request identity. The private request API is usable now; the visible UI control is outstanding.
