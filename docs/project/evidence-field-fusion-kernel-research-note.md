# 证据场融合研究笔记

日期：2026-10-30。状态：**设计建议，待用户审阅；未实现融合，未改变现行计划顺序。**

## 已确认约束与本轮结论

- 融合支持输出非负、越大表示对声明命题的支持更大，通常为 `[0,1]`；不表示布局好坏。原始距离、角度、带符号观察和状态完整保留。
- 原始量越低越好时，由包输出函数在合法定义域内作单调方向转换；倒数只是例子，不对零或带符号量盲套 `1/x`。
- 包间及包内重要性权重均未知。不存在仅凭未知权重便能推出的唯一“客观公平总分”；等权必须明确是默认假设。
- 正式底层保留完整证据向量。需要单值成场时，建议首版采用**等语义证据族均值**，并列保留向量、覆盖和权重敏感性诊断；不只交付区间而回避成场。
- `[0,1]` 统一方向与范围，不证明不同包的 `0.5` 含义等价；可比语义仍须由各包输出规则说明。

2026-10-29 的直接累加/均值与 `x/(x+τ)` 草案由本轮研究取代，仍非已批准公式。
本笔记不启用单体家具渠道，不产生硬分组，不新增依赖或第二套场内核。

## 方法能解决什么

| 方法 | 适用语义与本项目判断 |
| --- | --- |
| 等权均值 | 假设贡献可补偿且同一贡献单位；不需学习权重，但等权本身是选择。建议作为首版单值默认，明确标注。 |
| `max` / fuzzy OR | 表示“任一充分理由即可支持”。能保留强证据，其他渠道不改变最大值；不适合作为所有证据通用融合。 |
| `min` / fuzzy AND | 表示“所有条件均必要”。最弱项限制结果；只有必要前提语义明确时使用。 |
| soft OR：`1−∏(1−s)` | 可作为模糊运算，无须随机独立；若解释为概率并集才需独立模型。重复贡献会增分，多项易饱和。 |
| 中位数/截尾均值 | 两项中位数等于均值；截尾会让部分渠道不影响总数。不能通用解决真实强弱差异。 |
| Choquet 积分 | 可描述冗余/协同，但需要容量或交互参数；目前没有这些参数。 [R2] |
| CRITIC 等数据权重 | 用离散程度和相关性定义权重；“变化大/不相关”不等于“对分组重要”，且随样本变。 [R3] |
| Bayes / 证据理论 | 需要似然、依赖或证据赋值规则；本项目目前缺这些模型。Bayes 可表示重叠边际事件，重叠本身不是禁用理由。 |

聚合函数的选择表达“充分、必要、可补偿”等规则，不是纯数值清洗。 [R1]
因此包内有自身逻辑，不应自动把所有渠道套同一个均值、最大值或 soft OR。

## τ、极端值与归一化

`x/(x+τ)` 中，`x=τ` 恰好输出 `0.5`。τ 决定半支持位置，必须有几何/语义依据，
不能称为无需假设的客观参数。自然有界的 `cos²(δ)`、clarity 不再套此函数。
距离映射 `L/(L+d)` 只是候选；选什么 `L` 仍是实质设计，未批准。

把支持限制在 `[0,1]` 可限制单项数值影响，却不会消除渠道冗余、语义不齐或错误映射。
z-score 描述相对样本偏离，可能为负且随场景变化；不直接满足本项目的支持输出要求。
真实极端证据与错误异常值不能混同；先检查来源、状态和映射，不能为压极端而删渠道。

## 建议的首版融合设计

### 1. 完整向量是正式底层

```text
E(g, k, scope) = [s₁, s₂, …, sₘ] + status + coverage + provenance
```

`g` 是家具组，`k` 是一个场/组织视图的身份。不同场可重叠，不要求同一家具组
跨场支持和为 1。所有参与融合的项须回答同一 `g→k` 问题，使用同一分析平面、
冻结全作用域与版本，且说明支持含义。关系读数不能未经映射便充当归属。

现有组对关系和全场合力**尚不等于** `sₚ(g,k)`；场身份/提议及关系到参与支持的映射
仍待设计。融合公式不会自动补齐这一步，当前不能宣称已有可运行的联合场。

### 2. 需要单值时，默认等语义证据族均值

```text
F(g,k) = (s₁ + … + sₘ) / m
```

这是待审阅的首版可执行设计建议：假设固定配方中的语义证据族同等贡献、允许补偿。
它保持非负、范围有界、逐项单调。新增证据可能提高也可能降低均值，不能保证总值增加。
新增族构成新 recipe；同一公式不代表跨 recipe 自动可比。数值旁始终保留全部渠道。

只在同一问题、语义可比、固定配方且覆盖完整时输出完整均值。缺失不填零，
也不按碰巧可用项重新除；未知支持可暂记 `[0,1]`，得到固定分母下的不确定范围，
但不冒称完整均值。无效/不适用状态按已审阅的配方规则处理，不临时改变分母。

### 3. 未知权重的旁侧敏感性诊断

若接受非负凸组合与可补偿假设：

```text
F_w = Σ wₚ sₚ，wₚ ≥ 0，Σwₚ = 1
全部可能分值范围 = [minₚ sₚ, maxₚ sₚ]
```

这是 owner 的代数推导：**权重不确定性界**，不是置信区间、概率、实际归属、
去极端方法或公平性证明。不同对象比较时必须使用同一组全局权重；
逐渠道占优有明确意义，区间是否重叠本身不是比较规则。可参考 SMAA 对未知偏好的处理，
但本轮不引入权重采样或排名算法。 [R4]

## 包内与包间如何公平

- 贡献单位是**语义证据族/来源责任**；当前每个独立、经审阅的包级支持算一个单位，不引入新的族注册机制。单位不按 Python 包、模块或渠道数量计数；拆包/改名不增加票数。
- 同一原始来源的重复派生不能各算独立票。相关而不同的特征既不自动独立，也不自动无用；保留来源并由包规则说明。
- 轴包四项关系不能通用平均或取最大：两个轴都模糊时 clarity similarity 仍可高；它不等于强方向支持。
- 轴的全场 resultant 使用同批轴，不作为额外独立投票。接触与正面积重叠也未被批准为自动支持。
- 包可以按充分/必要/补偿等语义组合，但须保留原始量、派生量、逻辑/参数/版本及全部渠道；外层仅融合声明的同问题支持。

## Space Syntax 与实现复用

Space Syntax 将空间关系建图，按问题选择拓扑步数、角度代价、距离、整合度/选择度；
角度网络分析展示了“关系定义决定路径成本”的方法。 [R5]
NAIN/NACH 针对网络大小及角度整合/选择的归一化，不是任意证据的通用可比量尺。 [R6]
可借鉴其**分开关系图、路径语义与目的性归一化**，不能把中心性直接当家具组归属。
`depthmapX` 有公开实现；本轮只作算法参考，不导入其分析管线。 [R7]

SNF 将对齐的相似矩阵经局部邻域、KNN、迭代与重新归一化融合；它需要邻域/尺度/
迭代等选择，且会传播关系，不能当成无参数的 drop-in 场内核。 [R8]
`scikit-fuzzy` 的 `fuzzy_or` 实现 `max`，能核实运算语义但不决定本项目的支持映射。 [R9]
现有 NumPy/NetworkX 足以实施经审阅的向量、均值与诊断，无须新增融合依赖。

## 与现有代码对接及后续

- `features/field_core.py` 的 `EvidencePackageOutput` 已保留源 envelope、派生输出、状态、量尺与来源链；“additive outputs”指追加渠道，不是数学求和。
- `EvidenceOutputScale` 当前校验量尺边界元数据；未验证 observation 实际范围，也未强制“越大越支持”。
- 几何包组级聚合仍 deferred；成员渠道仍 audit/suppressed。轴包已有关系/合力，但没有正式 `g→k` 支持映射。
- 用户审阅后，先定场身份与支持目标、各包映射及包内逻辑；再在既有输出契约补支持值有限/非负/范围及方向声明校验。范围检查不证明科学可比或语义单调。
- 随后用同一指定 IFC、同一平面/作用域对照 geometry-only、axis-only、joint；不得构造模拟数据或训练权重。缓存、状态、来源追踪沿用既有机制。
- 本轮仅追加研究记录；现行 checklist 中 Frame 包的下一步顺序未被静默改写。
