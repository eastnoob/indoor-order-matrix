## 决策摘要

2026-10-15 scope correction: this is an installable unified Analysis workbench, one station toward long-term delivery. Its independently collapsible Domain and Free-space sections deliver all existing B4 tools and the new free-space workflow. Later operations join the same UI/service boundary incrementally. B4 retains its service/reducer; free-space retains AnalysisRequest/Field. Shared capture/identity/confirmed-domain/result access does not create a framework or coerce both lifecycles into one request.

## Current-tree prerequisite and final seam resolutions

Read-only current-tree inspection: `features/analysis_requests.py`, `adapters/bonsai_analysis_plane.py`, `scripts/design/space_field/capture_b3_live_scene.py` and `run_b3_live_analysis_request.py` are **CURRENT TREE ABSENT**. `features/_analysis_domain_handoff.py` and both `scripts/design/live_domain/{blender_panel,run_live_domain}.py` exist. API signatures, regressions and capture behavior quoted from Spec003 are Git `23d24a3` reference evidence, not current implementation claims. T0 requires the version specialist to restore and verify the entire approved dependency/import closure in an isolated clean environment, preserving dirty history; missing Spec003 docs are read with `git show 23d24a3:<path>`, never copied as a second spec. No such restore/test was executed in this design pass.

The final design uses actual structural_scene/context (datum0/cut1.5/XY basis) for B4, current full-capture validation before Start, and stable canonical structural/full digests. Stable digests include project/source/geometry/transform/version facts; exclude timestamps/runtime pointers/job or capture IDs/selection/dirty/camera/IFC transaction/mtime, with occupancy-only facts also excluded from structural digest. The reducer wiring is explicit: `source_revision` is the stable structural-source-facts digest and `frame_id` is the canonical `structural_frame_key`; T0/T1 must verify the actual reducer arguments rather than comparing wrapper tokens. Detailed minimum records live in data-model.

SupportBinding is validated uniquely then mapped source_object_id→source.source_id (GlobalId) only in a request-scoped child domain reaching `_scope_exclusions`; shared inferred B4 source_id remains None. Unknown support distinguishes valid_nonempty, validated_empty and missing/malformed; qualified empty requires successful trusted identity/query/complete-coverage evidence. Failed targets or incomplete/ambiguous multi-owner evidence stay global unknown.

Addon imports stay lightweight; Shapely/heavy core and clipped display triangulation run in Pixi. Capture/JSON/Text/mesh/polling use bounded main-thread work with measured elapsed/bytes/counts and explicit overrun handling. Unknown support reuses the existing affine frame mathematics exactly once while preserving polygon, line, point and qualified-empty GeoJSON; translated-origin line/point touch tests are required. Save Copy failure retains live truth and cleans only owned partials; the injected native `save_as_mainfile` exception test must record no artifact until a later success. Reopen is historical/unverified and fresh Start verifies IFC/project/GUID/fingerprint/bindings. CameraBinding is display-only, absent from geometry/keys/occupancy.

Native commands use `--python-exit-code 1`; background smoke pumps real runtime timers/bounded main-thread work until the real async job and successful report exist, failing on timeout. Output root is `D:\PROJECTS\understandOtherPackage\order_analyzer\outputs\design\blender_analysis_workflow\run_<UTC-and-UUID>`. Read-only jj 0.45.1 audit uses `jj --ignore-working-copy status` and `jj --ignore-working-copy diff --summary`; delivery later requires an isolated clean workspace and hash-validated delta/approved dependency closure, never a blanket snapshot. User review starts at spec/plan; supporting artifacts need no separate signatures.
